# History

Documents that record how the project got to its current state. They are kept for reference
and are **not** a description of the current state — for that, see the newest
`docs/STATUS_<date>.md`. Statements in these files may be out of date or wrong (several are).

* `WORKLOG_2026-10.md` — running log of the solver work of 2026-10-01/02: bugs found, hypotheses
  (some later shown to be wrong; the log says so where it was corrected), and results as they came
  in. The commit messages of that period have the details.
* `2026-08_session/` — notes from the AI-assisted sessions of 2026-08-04/05. **Caution:** their
  central diagnosis (a "duplicate `kam_torus()` call" as the bug) was wrong; the real bugs were
  found and fixed in October. Includes the August status, analysis, verification and
  reorganization notes, and the August versions of the Julia and paper READMEs.
